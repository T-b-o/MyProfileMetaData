## 📖 Description
This is my web-based resume built with HTML, CSS, and JavaScript. It showcases my skills, experience, projects, and contact information in an interactive, modern format that's accessible from any device.

## ✨ Features
- 📱 **Responsive Design** - Works on mobile, tablet, and desktop
- 🎨 **Modern UI/UX** - Clean, professional interface
- ⚡ **Fast Loading** - Optimized for performance
- 🌓 **Accessible** - Follows web accessibility standards
- 📄 **Print-Friendly** - Clean print formatting

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting:** GitHub Pages
- **Version Control:** Git & GitHub
- **Icons:** Font Awesome / Material Icons
- **Fonts:** Google Fonts
